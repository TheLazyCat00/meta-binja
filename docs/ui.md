# UI behavior

The initial UI is a Binary Ninja sidebar with two states: search/results and a plugin management page.

Search accepts normal text or a repository URL. Activating a result opens its management page with source, repository, version/status, enable/disable, install/uninstall, and update controls.

This is intentionally the first replacement-style surface; a larger dedicated pane/window is planned once the lifecycle behavior has been exercised in real Binary Ninja builds.
